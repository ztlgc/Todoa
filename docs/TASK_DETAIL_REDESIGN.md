# 任务详情改造

## 操作

- 顶部：完成任务、日期与提醒、优先级、关闭。
- 中部：直接编辑标题和内容。正文支持加粗、斜体、下划线、删除线、高亮、列表、链接、图片及撤销重做。Ctrl+B 加粗。
- 选中文字时，格式工具栏悬浮在选区上方，不参与正文布局；空间不足时自动避让。底部格式按钮也打开悬浮工具栏。Esc 先关闭格式浮层，保留任务详情。
- 优先级旗帜下方显示160px宽的紧凑菜单，选择后即时保存；无需打开页面中央的对话框。
- 底部：选择所属清单，打开格式工具，管理标签；更多菜单内移入回收站。
- 点击日期进入月历，设置时间、重复和提前提醒；确定统一保存，关闭取消草稿。选择“无时间”保留全天日期并清空自动提醒。独立提醒使用单独管理入口，其操作即时保存。
- 提醒可先勾选，保存前须补齐日期和时间。预设为准时、提前5分钟、提前1小时、提前1天、提前3天；自定义输入“提前数量＋小时／天”。已有其他分钟提醒保留为可移除选项。
- 重复选择中提供“自定义重复”，点击弹出“每几天／周／月／年”输入；应用后仅修改时间浮层草稿，取消不改动。
- 支持 PNG/JPEG/WebP 文件、粘贴图片及拖入图片，单图最多 10MB、4000 万像素。双击图片预览，选中图片后可填写说明或删除。

## 保存和兼容

标题及正文停止输入约 800ms 后自动保存，关闭详情及完成任务前先保存。中文组合输入期间不提交。失败保留本地草稿并提供重试；重开详情可选择恢复草稿或保留数据库内容。正文修订号用于拒绝旧版本覆盖新版本。

桌面数据库版本为 6，在日记版本 5 基础上增加正文 JSON、修订号、全天日期、图片 BLOB 和资源引用。现有备注按换行读取为段落，纯文本摘要仍保存在 notes 中。启用的 Tiptap 节点和格式构成第一版正文格式，由原生保存接口检查；JSON 不存外部图片地址。

图片直接包含在数据库备份中。任务移入回收站保留图片，重复任务共享不可变资源引用。为了支持撤销和未保存草稿，已从正文移除的图片引用保留至任务永久删除；最后一个引用删除后清理资源。当前资源表保存 MIME 和二进制，图片大小由 BLOB 约束，尺寸在导入时检查，未单独保存尺寸或校验摘要。

只有日期的任务使用 due_date，日期加时间使用 UTC due_at；日期筛选、日历、统计和重复生成支持这两种形式。提醒必须明确选择时间。

浏览器任务和图片是临时数据，刷新清空。桌面草稿使用 localStorage，浏览器草稿使用内存，与任务一起在刷新后清空。应用突然关闭时依靠本地草稿恢复，尚未验证 Windows 关闭过程中的原生保存等待。

# 工作日记与阶段回顾

日记用于自由记录每天的工作，再从记录中收录值得保留的重点，整理月度和年度回顾。顶部提供「每日」「月度回顾」「年度回顾」「搜索」四个入口，默认打开今天。

## 每日记录

左侧月历选择日期，绿色表示当前选择，小圆点表示当天有记录。可翻看月份、回到今天，也可使用前一天、后一天和日期选择器。只翻月历月份不改变正在编辑的日期。

「今日工作记录」是主要输入区，支持格式、列表、链接，以及插入、粘贴或拖入 PNG、JPEG、WebP 本地图片；单张不超过 10 MB。可选「插入回顾提纲」追加主要工作、进展与结果、问题与体会，不要求填写客户、业务类型或状态。

「已完成任务」自动列出主任务完成时的标题、时间和备注快照，备注可以展开。没有完成任务也可以写工作记录。当天取消完成会撤回对应自动条目，跨日取消保留原快照及撤销时间；原任务后续修改或删除不改写历史快照。重复请求和启动补录去重，子任务不单独归档。

月历下方保留「查看本周记录」，按周一至周日阅读每日原文；打开某一天回到每日编辑。旧周总结可通过搜索打开，旧月、年总结直接使用对应周期的回顾编辑器，原文不会被模板覆盖。

## 收录重点

可选中正文的一段文字，点击「收录选中内容」，也可从完成任务点击「收录重点」，或直接「添加重点」。仅摘要必填，结果说明和工作主题可不填。同一任务再次收录会打开已有重点。选中文字创建的是文本摘录，不依赖不稳定的段落位置，也不会自动推断业务成果。

重点独立保存，编辑、删除重点不改写原始日记。来源日记更新时提示来源变化；来源进入回收站或任务完成被撤销后，默认不再作为可用素材显示。已经插入回顾的文字保留当时的摘录并显示来源状态。删除重点需要确认。

编辑重点时，先保存或取消再切换日期、页面。重点保存失败保留当前表单；正文沿用独立的草稿恢复机制。

## 月度与年度回顾

「月度回顾」包含独立的回顾正文和本月素材。素材按工作主题分组，同一主题内按日期排列，可按主题筛选并打开原始日记。「加入回顾」明确插入发生日期、摘要、结果、主题和来源；不自动把全部完成任务堆进正文。已加入的来源不能再次添加。

回顾正文可以自由编辑，也可追加主要工作、重要进展与成果、问题与经验、下月关注提纲。「查看本月全部原始日记」列出当月日期，无需先收录重点就能找到原文。

「年度回顾」提供全年重点和十二个月的月度回顾入口。可以从重点直接整理，也可选择已有月度回顾；不要求先写齐十二篇月总结。年度提纲包含年度主要工作、重要成果与关键事件、能力与经验、遗留问题、下一年方向。当前年份注明记录截止日期，未来月份不可加入。

年度同时使用月度回顾和原始重点时，通过关联来源 ID 检查重复；若月度回顾包含已加入的重点，或重点已随月度回顾加入，拒绝重复追加并提示。不会对手写文字做模糊语义去重。

「按月查看全年原始日记」只展开所选月份的日期索引，打开具体日期才读取完整正文；年度首屏不挂载全年富文本和图片。宽屏正文与素材分栏，窄屏改为上下排列。

## 搜索、导出与回收站

搜索提供关键词、起止日期和「只看重点」。结果展示日期、类型、命中片段，点击打开来源日记或对应回顾；关键词覆盖正文、历史事项、任务快照、重点和回顾文字，不识别图片内文字。普通结果按每页最多 50 篇从数据层查询；只看重点从所选日期范围的重点中筛选和分页。

更多菜单区分「导出当前日记」「导出当前回顾」「导出本月原始日记」「导出全年原始日记」或「导出本周原始日记」，文件名包含日期和范围。主题筛选和搜索不会悄悄改变导出范围。Markdown 保留正文格式和嵌入图片，整篇上限 32 MB；嵌套列表复用单次图片读取，代码块保留末尾空格和换行。

移入回收站需要确认。删除后不会被自动归档重新恢复，恢复日记保留原文、格式、图片、任务快照和来源关联。搜索入口的回收站可查找并恢复历史日记。

## 保存与数据

停止输入约 650 毫秒后自动保存。切换日期、页面或离开日记前先保存最后输入；中文输入法组字期间不提交。失败显示重试并保留当前输入和本地草稿，重开后可以恢复或舍弃。版本冲突不会覆盖另一窗口已保存内容，可先读取已保存内容，再决定是否恢复草稿。

图片导入结束后重新安排自动保存。旧编辑器或快捷草稿只有在新版草稿或正式日记成功写入后才清理；草稿写入失败时，「读取已保存内容」保留当前输入。正文按去掉末尾空白后的 UTF-16 长度校验，上限 200000。

停留在今天时，跨午夜先保存旧日期内容，再跟随新的一天；组字、图片导入或保存失败解除后继续尝试。主动选择历史日期会取消自动跟随。

桌面版使用 SQLite Schema 9：`journal_records` 保存每日和周期文档及独立内容版本，`journal_task_completions` 保存完成快照，`journal_assets` 保存归属于各篇日记的图片；新增 `journal_highlights` 保存重点，`journal_review_sources` 保存回顾与素材的来源、快照和版本。追加回顾正文和写入来源关联在同一 Rust 事务中完成；版本冲突、超长或写入失败时整体回滚。命令仅主窗口可用，不扩大 Quick Add 权限。

Schema 8 升级只增加新表和索引，不重写旧日记。已保存日记、图片、重点和来源关联共同参与数据库备份与恢复，兼容既有受支持版本的备份。未提交的本地草稿不随数据库备份。

应用启动及日记编辑器关闭后尝试回收无引用图片。所有打开编辑器的撤销历史、在途保存、已保存正文、回收站和本地草稿均受保护；无法解析引用或缺少 Web Locks 时跳过清理。清理不永久删除日记，不缩小现有备份，也不保证 SQLite 文件立即变小。

浏览器为独立调试环境：任务刷新后清空，日记保存在 localStorage，图片在 IndexedDB，刷新后保留。重点使用单独版本键；回顾正文和来源关联嵌在同一个日记存储值中，一次写入，配额失败不留下半份回顾。清除站点数据会删除浏览器数据；浏览器与桌面数据库互不相通。

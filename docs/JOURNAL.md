# 工作日记

2026-10-07：在已确认的页面上接入真实记录、任务素材和独立总结。

## 使用方法

在一级导航进入「日记」，选择日期，点击「写一笔」。填写当天总结，可手写工作进展，也可从当天完成的任务中收录素材；勾选「包含未完成任务」可补充正在推进的工作。每一项可以补充备注、主题并标记重点。点击「保存日记」写入记录；切换页面或日期前会提示未保存的修改。

「日／周／月／年」切换浏览范围。周从周一开始，月和年按自然周期计算。周总结、月总结与年度总结分别保存，点击「整理本期素材」将已有记录追加到草稿，仍由用户提炼和保存；该操作不会覆盖已有正文，也不调用 AI。年度页面展示十二个月的工作足迹，方便逐月回看。

搜索、主题与重点筛选用于查找记录。「导出」将当前周期及筛选范围导出为 Markdown。删除记录进入独立的日记回收站，可以恢复，不删除原任务。

## 数据规则

- 同一日期一篇日记，同一周／月／年各有一篇总结，四种记录独立保存。
- 收录任务保存标题、备注、完成时间等快照。后续修改或删除原任务不会修改历史日记。尚可找到原任务时支持查看其当前内容。
- 桌面端使用 SQLite `journal_records` 表（迁移 0005），随数据库备份和恢复。旧版备份通过现有迁移机制升级。
- 浏览器端使用独立的 `todoa.journal.v1` localStorage，刷新后保留日记；浏览器任务仍是临时数据，二者与桌面数据库隔离。清除站点数据会删除浏览器日记。
- 保存使用版本号检测并发修改。写入失败或版本冲突保留当前输入；损坏的存储会显示读取失败，不会静默清空。

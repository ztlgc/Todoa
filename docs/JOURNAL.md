# 每日工作日记

日记面向银行对公客户经理，页面只保留当天完成的任务和一个完整的工作补充编辑区。

## 日常使用

进入「日记」默认打开今天。完成任务后，系统按实际完成时的本地日期自动生成当天日记，后续完成任务追加到同一篇。清单显示任务名称和完成时间，点击展开当时的任务备注。

在「工作补充」直接输入客户沟通、走访情况、业务进展或次日安排。编辑器与任务详情共用，支持格式、列表、链接，以及插入、粘贴或拖入 PNG、JPEG、WebP 本地图片；单张不超过 10 MB。无需填写标题、客户、业务类型、记录类型或事项状态。

停止输入约 650 毫秒后自动保存；切换日期或离开日记前会先保存最后一次输入。中文输入法组字期间不提交。保存失败会显示重试，保留当前输入和本地草稿；重开后可以恢复或舍弃。版本冲突不会覆盖另一窗口已保存的内容，可以先读取已保存内容，再决定是否恢复草稿。

左侧保留原来的月历，绿色表示选中日期，小圆点表示当天有日记。可翻看月份、点击日期或「今天」切换，切换前自动保存当前补充；只翻月份不会切换正在编辑的日记。也可以使用正文上方的前一天、后一天和日期选择器。历史入口支持按日期、任务和补充文字搜索。已有周、月、年总结保留在历史中，用同一编辑区查看和修改，不再提供周期工作台。旧日记标题、正文及手写事项会合并为可编辑内容，原始事项数据仍保留。

月历下方的「日／周／月／年」切换显示范围，以选中的日期为基准。周从周一到周日，月和年按自然周期计算；列表按日期从新到旧展示范围内每篇日记的完成任务、补充文字、格式和图片。上一周期、下一周期及「本周／本月／今年」可直接切换范围；点击月历日期会保留当前范围类型，点击列表中的「打开日记」回到当天编辑。范围切换前会先保存当前输入，保存失败时继续保留原编辑区。

范围视图只读取每日日记，回收站记录不显示。图片按进入视口的情况读取；浏览整年时无需打开大量编辑器。范围中的 Markdown 导出包含当前时间范围内的每日内容和图片。

「更多」提供 Markdown 导出和回收站。导出包含当天任务、工作补充及格式，图片嵌入文件。整篇导出上限 32 MB，超过时提示处理。删除日记后不会被自动归档重新恢复；恢复日记保留完成任务、补充文字、格式和图片。

## 自动归档与数据

自动任务快照和补充内容独立保存，新完成的任务不会替换编辑中的内容。当天取消完成会撤回对应自动条目；跨日取消保留原快照及撤销时间。重复完成请求和启动补录去重；修改、删除原任务不改写已归档快照。仅主任务完成生成记录，子任务勾选不单独生成日记。

应用启动后补录仍保留完成时间的历史任务。没有完成任务且没有手写补充的日期不写入空记录，但可以直接打开并补记。

桌面版使用 SQLite Schema 8：`journal_task_completions` 保存任务快照，`journal_records.content_json` 和独立内容版本保存完整编辑内容，`journal_assets` 保存属于该篇日记的图片。任务完成、提醒取消和重复实例生成仍在同一事务中。数据库备份包含已保存日记和图片，兼容既有受支持版本的备份。未提交的本地草稿不随数据库备份。

普通浏览器中，任务是刷新即清空的调试数据；日记保存在 localStorage，图片保存在 IndexedDB，刷新后保留。清除站点数据会删除浏览器日记和图片。浏览器和桌面数据库相互独立。

# Todoa 1.0.1

> 此版本存在数据库启动检查错误，请使用 [Todoa 1.0.2](https://github.com/ztlgc/Todoa/releases/tag/v1.0.2)。无需清空数据库。

发布日期：2026-10-07

Todoa 是一款本地使用的 Windows 待办应用。任务、清单、标签和提醒保存在本机 SQLite 数据库中。

## 本版更新

- 增加“已完成”和“回收站”视图，支持恢复已删除任务，并在回收站中确认永久删除。
- 完善任务详情、提醒和重复规则操作；支持清除重复规则并保留截止时间。
- 改进快速添加、完成热力图、日历和任务列表布局。
- 统一应用版本号为 1.0.1。

`Todoa_1.0.1_x64-setup.exe`：Windows x64 NSIS 安装程序。`SHA256SUMS.txt` 记录其 SHA-256 校验值。

安装包未进行代码签名。本版构建和自动化验证结果以项目记录为准；安装后的实际操作、Windows 11、通知显示、真实登录自启和跨显示器 DPI 尚未验收。本版没有自动更新服务。

# Todoa 1.0.5

发布日期：2026-10-19

## 新增与改进

- 面向银行对公客户经理重新整理工作日记。完成任务后按实际完成日期自动归档，同一天持续追加，启动时补录已有完成记录；保留完成时的任务名称、备注和时间。
- 日记使用一个完整的工作补充编辑区，与任务详情保持一致，支持格式、列表、链接、本地图片和自动保存。切换日期、显示范围或离开日记前先保存最后输入，保存失败时保留草稿并可重试。
- 保留左侧月历、选中日期及有日记标记，新增日／周／月／年浏览。逐日展示相应范围内的任务与补充内容，可打开单篇编辑，并将当前范围导出为含图片的 Markdown。
- 简化日记页面，移除业务类型、记录类型和事项状态等填写项。保留历史搜索、回收站和旧日记、旧阶段总结；自动任务记录与手写内容独立保存。
- 完善子任务编辑和任务卡片勾选、日期与提醒界面及宽屏任务详情布局，更新应用内使用说明。

## 安装与数据

完全退出旧版 Todoa 后，运行 `Todoa_1.0.5_x64-setup.exe`。应用身份仍为 `com.todoa.desktop`，升级沿用原有数据目录。建议先在旧版「设置 → 数据」创建数据库备份。

本版数据库升级至 Schema 8，新增任务完成快照、日记完整内容及图片存储；兼容既有受支持版本的备份。已保存的日记及图片随数据库备份，未提交的本地草稿不包含在备份中。

`SHA256SUMS.txt` 提供安装包 SHA-256 校验值。浏览器预览与桌面版数据相互独立。

## 验证与边界

前端 289 项、Rust 57 项和生产浏览器 19 组检查通过。详细结果及安装包信息见 [VALIDATION.md](https://github.com/ztlgc/Todoa/blob/v1.0.5/releases/v1.0.5/VALIDATION.md)，发布附件中也提供该文件。原生测试覆盖迁移、事务、备份恢复和图片归属校验。

安装包未签名。本次不覆盖用户现有安装或桌面数据库；安装后的完整操作、Windows 11、实际系统通知显示、真实登录自启和跨显示器 DPI 仍需目标环境验证。

构建仍保留既有的大于 500 kB 分包提示，本版未调整提示阈值。

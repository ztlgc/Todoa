# Todoa 1.0.3

发布日期：2026-10-07

## 新增与改进

- 重新设计任务详情，支持加粗、高亮、列表、链接和本地图片；日期、重复及提醒统一在日期面板中设置。
- 新增工作日记，支持每日任务快照、周／月／年总结、搜索、重点标记和 Markdown 导出。
- 改进清单与标签管理、任务完成筛选和日历交互。
- 改进数据库备份与恢复，并保留日记和任务图片内容。

## 安装

请完全退出旧版 Todoa 后安装 `Todoa_1.0.3_x64-setup.exe`。`SHA256SUMS.txt` 提供 SHA-256 校验值。

安装包未签名。Windows 11、安装后的完整操作、系统通知、登录自启和跨显示器 DPI 尚未验收。

# Todoa 1.0.0

发布日期：2026-10-06

Todoa 是一款本地使用的 Windows 待办应用。任务、清单、标签和提醒保存在本机 SQLite 数据库中。

## 本版功能

- 收件箱、今天、即将到来、清单、标签和月历视图。
- 任务详情编辑，包括截止时间、重复规则、提醒、标签、备注和四档优先级。
- 自然语言快速添加、独立快速添加窗口、全局快捷键及系统托盘。
- 本地任务统计、数据库备份与恢复、开机启动设置。

## 安装包

`Todoa_1.0.0_x64-setup.exe`：Windows x64 NSIS 安装程序。`SHA256SUMS.txt` 记录其 SHA-256 校验值。

安装包未进行代码签名。当前验证覆盖 Windows 10 x64 开发机上的构建、自动化测试及隔离身份原生界面检查；1.0.0 安装后的实际操作、Windows 11、通知显示、真实登录自启和跨显示器 DPI 尚未验收。本版没有自动更新服务。

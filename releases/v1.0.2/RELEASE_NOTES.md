# Todoa 1.0.2

发布日期：2026-10-07

## 修复

- 修复 1.0.1 在数据库迁移成功后仍显示“本地数据库未能安全启动”的问题。启动检查现根据当前数据库版本核对完整迁移历史，并将前端版本检查同步为 4。
- 原数据库可继续使用，不需要清空或重建。

## 安装

请完全退出旧版 Todoa 后安装 `Todoa_1.0.2_x64-setup.exe`。`SHA256SUMS.txt` 提供 SHA-256 校验值。

安装包未签名。修复通过 9 项数据库启动及升级回归测试，并在隔离桌面应用中实际打开收件箱；安装后的完整操作、Windows 11、系统通知、开机启动及跨显示器 DPI 尚未验收。

# Todoa 1.0.4

发布日期：2026-10-08

## 新增与改进

- 完善自定义重复：支持每周多天、月内多个日期、每月第一个／最后一个工作日、相对星期、间隔、指定日期列表及结束日期／次数；提供后续安排预览。
- 重新设计日期与时间选择界面，缩小日期浮层，重复菜单和提醒单位沿用应用风格；未设置具体时间时默认 09:00，可选择无时间。移除任务日期面板中的独立提醒管理入口。
- 设置新增“功能设置”，可以隐藏或恢复日历、日记入口，保留已有数据。
- 设置新增“提醒与通知”，提供系统通知开关、任务标题显示选项和系统测试通知按钮；移除免打扰设置，旧免打扰偏好不再影响通知。
- 完成热力图按可用宽度从左到右排满后换行，随窗口宽度调整，键盘导航跟随实际列数。

工作日指周一至周五，不含法定节假日和调休日历。详细规则见仓库中的 docs/RECURRENCE.md。

## 安装

完全退出旧版 Todoa 后，运行 `Todoa_1.0.4_x64-setup.exe`。升级保留原应用身份和本地数据库；建议先在“设置 → 数据”创建备份。

`SHA256SUMS.txt` 提供安装包 SHA-256 校验值。

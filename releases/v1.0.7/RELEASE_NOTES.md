# Todoa 1.0.7

发布日期：2026-11-16

## 修复与改进

- 修正“下周”“本周”“大后天”、每周多个星期及周末等输入识别，非法日期、时间和不支持的范围表达保留原文，避免误改任务标题。
- 完善日期与时间选择、相邻月份导航、全天切换和年份边界。原样确认时保留原截止时刻的秒与毫秒，未修改的过期提醒不再阻止保存。
- 修复年度固定日期、闰年、月末、长期逾期和重复结束条件；统一前端与桌面端夏令时跳跃和重叠时刻处理。
- 防止撤销后再次完成、删除后续任务或备份恢复后重复生成任务；后续任务生成失败时，完成状态、提醒和重复进度整体回滚。
- 撤销完成时恢复未来的规则提醒，不补发过期提醒、不重放已有触发记录；全天重复任务不产生时间提醒，清除唯一日期时同时停止重复。
- 日记切换日期和回顾时先读取目标内容，读取失败保留当前页面；切换期间继续输入的内容会再次保存，减少滚动位置跳动。
- 调整应用与文档介绍，统一使用通用的待办、日程和工作日记表述。

## 安装与数据

建议先在旧版「设置 → 数据」中创建数据库备份，完全退出旧版后运行 `Todoa_1.0.7_x64-setup.exe`。应用身份为 `com.todoa.desktop`，升级沿用原有数据目录。

本版数据库由 Schema 9 升至 10，新增重复任务处理进度；为已完成的重复任务回填进度，保留已有任务、日记和图片，进度参与备份与恢复。升级前已经撤销完成的旧任务没有历史处理进度可供追溯。手动创建的独立提醒没有规则偏移，撤销完成不会重建这类提醒。

# Todoa 1.0.6

发布日期：2026-10-31

## 新增与改进

- 日记顶部整合每日、月度回顾、年度回顾和搜索。每日页面继续保留月历、自由富文本、自动保存、任务完成快照、图片、回收站和周期阅读。
- 可从选中正文、完成任务或手动添加创建重点。重点拥有独立编辑和保存状态，并可查看或跳转到原始日记。
- 新增独立的月度、年度回顾正文和素材栏。可以把重点或月度回顾明确加入当前回顾，来源会随内容保留；系统按来源防止重复收录。
- 年度原始日记按月份展开日期索引，只有打开具体日期时才读取完整正文和图片，减少全年内容首屏加载。
- 搜索支持关键词、起止日期和只看重点，并可打开命中日记或回顾；导出明确区分当前日记、当前回顾及本周／月／年范围。
- 完成 2026-10-24 日记审计整改：改进草稿交接、图片导入后的自动保存、跨午夜跟随、孤立图片回收、正文长度校验、嵌套列表读取和代码块 Markdown 导出。

## 安装与数据

完全退出旧版 Todoa 后，运行 `Todoa_1.0.6_x64-setup.exe`。应用身份仍为 `com.todoa.desktop`，升级沿用原有数据目录。建议先在旧版「设置 → 数据」创建数据库备份。

本版数据库升级至 Schema 9，新增日记重点与回顾来源关联；升级只增加表、索引和关联记录，不重写已有日记。已保存日记、图片、重点和来源关联共同参与数据库备份与恢复。`SHA256SUMS.txt` 提供安装包 SHA-256 校验值。
